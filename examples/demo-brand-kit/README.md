# Slidekick demo brand kit

The brand kit the [launch deck](../demo-deck/) is built from: logos, `tokens.json`, a `.potx` template and a one-page guidelines PDF.

The template and the PDF are hosted in [aarshx05/aarshx05](https://github.com/aarshx05/aarshx05/tree/main/assets/slidekick/examples) so the plugin bundle stays text-only. To use the full kit:

```bash
curl -L -o deck-template.potx https://raw.githubusercontent.com/aarshx05/aarshx05/main/assets/slidekick/examples/demo-brand-kit/deck-template.potx
curl -L -o brand-guidelines.pdf https://raw.githubusercontent.com/aarshx05/aarshx05/main/assets/slidekick/examples/demo-brand-kit/brand-guidelines.pdf
```
