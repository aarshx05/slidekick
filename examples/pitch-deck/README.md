# Fernway seed pitch

An 11-slide seed pitch for a fictional startup, built with Slidekick from a brief and a brand kit made in this folder. It has native charts (revenue, a per-roof waterfall, market size), a native table, a Morph transition and Fraunces/DM Sans (OFL) fonts. All figures are illustrative.

Prompt: `/slidekick a 10–12 slide seed pitch for Fernway: rooftop greenhouses that grow produce on top of the grocery stores that sell it. Brand: deep green, terracotta, warm off-white, Fraunces + DM Sans. Show revenue growth, unit economics and market size as charts, and use Morph once.`

Download: [deck.pptx](https://raw.githubusercontent.com/aarshx05/aarshx05/main/assets/slidekick/examples/pitch-deck/deck.pptx). Decks are hosted in [aarshx05/aarshx05](https://github.com/aarshx05/aarshx05/tree/main/assets/slidekick/examples) so the plugin bundle stays text-only.

Rebuild (install the fonts in `brand/fonts/` first): `python ../../skills/slidekick/scripts/deck.py build -p .`
