Why the deck comes out right

  1. Designed as a canvas. The agent lays out every slide in HTML and CSS against your brand tokens, and Chromium solves the layout.
  2. Compiled to native PowerPoint. Each element becomes a real object: text boxes with runs and bullets, shapes, vector SVG, tables, charts with an embedded workbook, groups, transitions, animations.
  3. Checked in real PowerPoint. PowerPoint renders the file, /slidekick pixel-diffs it against the design and reads back what PowerPoint parsed. Problems get fixed before you open it.
  4. Reviewed by fresh eyes. A lint for near-misses, runts, type sprawl and AI-deck tells, then an independent reviewer scores 8 dimensions. It ships only when nothing is below 4/5.

Questions

Is the PowerPoint really editable?

Yes. Headlines are text boxes, bullets are real bullets, and charts are native charts with their data in an embedded workbook that you can open from PowerPoint. Transitions and animations are PowerPoint's own. Images are used only for photos and screenshots.

Do I need PowerPoint installed?

No. Without PowerPoint, /slidekick uses LibreOffice to check its work, which is a close approximation. With PowerPoint on Windows you get ground-truth QA, including readback of transitions and animations. PowerPoint for Mac is supported in beta for render checks.

Will it match my brand?

Give it whatever you have: logos, a palette, fonts, a .potx or .pptx template, design tokens or a guidelines PDF. It builds on your template's masters and theme. No kit? It can take the identity from your website or product.

Can it edit a deck someone else made?

Yes. Edit mode reads the deck first, then changes only what you asked for, in place. Untouched slides, masters and fonts stay as they were, and the result is re-rendered to catch any text that no longer fits.

Does my content leave my machine?

No. The pipeline runs locally. It goes online only to install its Python packages on first run, to fetch a Google Font you ask for, or to capture a URL you give it.

What does it cost?

Nothing. Slidekick is MIT-licensed. You use it with the agent you already have.
