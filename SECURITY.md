# Security

`/slidekick` runs locally. Your documents, decks and brand kits stay on your machine. It only uses the network to:
- download Google Fonts when you ask (`deck.py fonts fetch`)
- screenshot or download URLs you give it (`deck.py capture`, `deck.py fetch`)
- install its Python dependencies from PyPI on first run

To report a vulnerability, open a [private security advisory](https://github.com/aarshx05/slidekick/security/advisories/new) or email [12345.aarsh@gmail.com](mailto:12345.aarsh@gmail.com). Please don't file a public issue. You'll get a reply within a few days.
